# Mohamad Abdulazim — Portfolio (Vite + React)

Professional, recruiter‑friendly portfolio with a dark SOC aesthetic.

## Quick Start
```bash
npm i
npm run dev
```

## Build & Deploy
```bash
npm run build
# deploy the dist/ folder to GitHub Pages or any static host
```

## Project Structure
```text
src/
  assets/           # images and logos
  components/       # UI components
  styles/           # global styles
  App.jsx           # page composition
  data.js           # content data
  main.jsx          # React bootstrap
```

## Customize
- Edit `src/data.js` to update text, skills, jobs, projects, education, certs, and links.
- Replace `src/assets/avatar.svg` with your headshot (`avatar.jpg`), then update import in `Hero.jsx`.
- Colors and layout live in `src/styles/globals.css`.
